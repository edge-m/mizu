Mizu is a small TypeScript API server core for modern JavaScript runtimes. Define routes with typed contracts, compose async middleware, and run the same application through Fetch or the Node.js adapter.

## Why Mizu?

<CardGrid stagger>
	<Card title="Fetch-first" icon="rocket">
		The application boundary is `app.fetch(request)`, so tests and runtime adapters share the same interface.
	</Card>
	<Card title="Type-safe contracts" icon="setting">
		Request and response schemas use the Standard Schema interface, keeping validation independent from a single schema library.
	</Card>
	<Card title="Small building blocks" icon="add-document">
		Routing, context, middleware, cookies, security headers, and operational helpers are individually composable.
	</Card>
	<Card title="Node.js when you need it" icon="laptop">
		Keep the core runtime-neutral and add `mizu-node` only when you need a Node.js HTTP server.
	</Card>
</CardGrid>
